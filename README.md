<details>
<summary><b>01 &nbsp; I like assistants that do things.</b> &nbsp; — Open AURA's workshop</summary>

### From a sentence to an action

AURA is my ongoing personal assistant project. The public Python codebase includes voice components, tools, and a direct command path for familiar requests.

```text
"open chrome"  →  match a common command  →  run the tool
```

The interesting part for me: deciding when a simple, predictable command should go straight to a tool, and when a request needs more reasoning.

[Read the command-routing design](https://github.com/xsqlverx/AURA-V2/blob/main/docs/FASTPATH_OPTIMIZATION.md) · [Browse the tools](https://github.com/xsqlverx/AURA-V2/tree/main/tools)

</details>

<details>
<summary><b>02 &nbsp; I care about how an app feels.</b> &nbsp; — Explore arise's design decisions</summary>

### A useful next step beats another dashboard

The Android project in **arise** explores a simple question: what should I work on next? Its Evolve 1.3 implementation connects exam portions to selected syllabus topics, keeps instructions under “Why & how,” and breaks lessons into Start, Learn, Example, and Recall.

Kotlin, Jetpack Compose, Room persistence, and a matte-black interface give that idea a native home.

[Read the experience notes](https://github.com/xsqlverx/arise/blob/main/EXPERIENCE-1.3.md) · [Explore the app source](https://github.com/xsqlverx/arise/tree/main/app)

</details>

### Two different takes on education

- **[Skholario](https://skholario.vercel.app)** — explore subjects, start a study session, and track completed topics. A personal study project with illustrative curriculum data.
- **[Emerald Math](https://emerald-math.vercel.app)** — browse a tuition centre's courses and learning options.

Both projects have public source code. I'm interested in the space where clear structure meets an interface with its own identity.

[Skholario source](https://github.com/xsqlverx/Skholario) · [Emerald Math source](https://github.com/xsqlverx/Emerald-math)
